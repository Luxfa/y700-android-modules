## 发布版做过的处理（不是原样拷贝）

1. **脱敏替换**：设备序列号 → `YOUR_SERIAL`；内网地址 → `192.0.2.10`（RFC 5737 文档地址段）；手机号/邮箱/Windows 用户名/主机名 → `YOUR_*`；家庭 WiFi 名 → `<SSID>`；蓝牙耳机名 → `<BT_DEVICE>`；所有 MAC 地址 → `<MAC>`；WiFi Direct 广播名（含 wpa_supplicant 打印的**转义字节形式**）→ `<BT_DEVICE>`；一加/OPPO 互联的两台设备 ID → `<DEVICE_ID>`；线刷包解包口令 → `${PACK_PASSWORD}`（**明文口令不发布**）。
   注意：**手机号只替换已知那一个**，通用 11 位正则会误伤文档里作为证据的字节数（`13185433600` 恰好是 `super_4.img` 的大小）。
2. **结项报告 §十 整节略去**：原文记录"哪些文件含隐私信息"，等于把个人信息位置指给外人，对读者又无技术价值。
3. **未发布的内容**：
   - **截图**（视野 AB 31MB、色彩排查 9MB）——屏幕截图可能带账号头像、便签内容、WiFi 名，需要逐张人工看过才敢发，本轮只发文本取证。
   - **游戏二进制存档**（`playerprefs_*.sav`）——不是我们写的东西，且属设备侧数据。
   - **`00_救生包/资产清单.md`**——含解包口令。
   - **任何固件、镜像、APK、`.so`**。
   - 文中出现的"流水账 §某某""见 04_日志与分析/xxx"若指向未发布件，请当作内部索引，**不影响结论阅读**。
4. **大件文本走 gzip**（>300KB 的日志，28 件）：压缩不删证据，`gunzip 文件名.gz` 即还原；`tombstone_*.txt` 与 `logcat_merged.txt` 保持明文，方便直接 grep。
5. **SurfaceFlinger dump 里的 NUL 字节已剔除**（每份 13,317 个）——那是 dumpsys 输出带的填充，去掉不改变矩阵读数，否则 GitHub 会把文件当二进制不渲染。

## 状态词约定（全套文档统一）

`【实测】`= 包内或机上直接读到 ｜ `【推断】`= 机理推测，未取证 ｜ `【多人实测】/【单人经验】`= 网络调研口径 ｜ `【AI稿已剔除】`= 内容农场来源，不采信 ｜ `未做 / 已装未验证 / 验证通过 / 判死 / 已回退并复验` = 改动状态，**不许用"通过"描述数据无效的项**。
