编写一个 **Git Bash 脚本**（Windows 侧运行，通过 adb 操作已 root 的 TB323FU），完成关键分区 dd 备份。

## 功能要求

1. 前置检查：adb 设备在线、`adb shell su -c id` 返回 uid=0，否则明确报错退出
2. 备份方式：`adb exec-out "su -c 'dd if=<节点>'" > <本地文件>.img`，不落 /sdcard
3. 备份清单（节点以 by-name 存档为准）：
   - 必做：persist、oemowninfo、modemst1、modemst2、fsg、fsc、devcfg_b、modem_b、init_boot_b、boot_b、vendor_boot_b、dtbo_b、vbmeta_b、vbmeta_system_b、metadata
   - 可选（`--full` 参数时追加）：super（约20GB，getvar 显示 0x500000000）、devcfg_a、modem_a、init_boot_a
4. 每个文件备份后：校验实际大小与 getvar 存档中的 partition-size 一致；算 SHA256；试读前1KB确认非全零
5. 产出备份日志 CSV（分区名、文件、大小、SHA256、时间），格式与 `05_备份索引/备份登记表.md` 表头对齐
6. `--dry-run` 模式：只打印将执行的命令不执行
7. 脚本顶部注释写明：用法、依赖、风险（仅供本机 YOUR_SERIAL 使用，禁止刷入他人镜像）
