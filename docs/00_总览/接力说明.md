## 血泪坑（本轮新增的都标了日期）

1. 官方 9008 包是单槽设计，刷完要激活槽位，否则 bootloop（11-22 踩过，有专条记忆）
2. 锁 BL 下 `fastboot set_active` 被禁，切槽只能 fh_loader
3. 刷写命令照官方 bat 原样执行，不擅自删 patch
4. firehose 会话卡死 → 拔线等 3 分钟让设备侧超时自清
5. 9008 全零 GPT 占位 bin 禁止裸写；fastboot 必须插**侧边中置**口
6. **"脚本执行了"≠"动作生效了"**：Magisk post-fs-data 阶段 `/product/bin/resetprop` 等 tmpfs applet 还不存在，静默失败；日志必须逐条记 旧值→新值（11-23）
7. toybox `grep` 不支持 `\|`，必须 `-E`；cil 规则源/目标可以是集合 `{ a b }`，单类型正则会漏判（11-23）
8. `su -c '... &'` 起的后台进程会随会话被回收，**必须 setsid**；`pgrep -f` 会匹配到 su 包装造成"实例=3"假象（11-24）
9. `adb push` 写不进 `/data/adb/modules/`，要先 push 到 `/data/local/tmp` 再 `su -c cp`；同名文件多模块共用暂存目录会互相覆盖，暂存名必须带模块前缀（11-24）
10. **`settings get` 失败时错误串走 stdout 不走 stderr**，直接 `>文件` 会把垃圾存成配置值；必须先取回再校验取值域（11-24）
11. 响应类功能（自动亮度/环境色）验收必须用**远大于时间常数的连续窗口**，并用"读数逐位不变"区分阻尼与停摆；短窗采样曾三次让我得出相反结论（11-24）
12. 验证"放行类"策略，样本里必须包含一次**真实的被保护动作**；开机空闲期数出 0 拒绝是必然的、不构成证据（11-23 定，11-24 我自己又违反一次并撤回结论）
13. 只读解析工具要**先拿必然存在的关键词自证**（`apk`/`bin` 命中 0 说明遍历坏了，不是内容不存在）；EROFS 多 pcluster 解码对 17MB 级大文件仍会失败（11-24）
14. Git Bash 会把 `/priv-app/...` 这类参数转成 Windows 路径，必须 `MSYS2_ARG_CONV_EXCL='*'`；中文目录给子代理派单时路径易乱码，让它自己用 ASCII glob 发现路径（11-24）
15. **`git add` 没报错 ≠ 文件进了库**：ignored 路径被静默跳过（本项目 `*.log` 曾把 247 件 9008 刷写证据全挡在库外）。入库动作完成后必须用 `git ls-files` / `git check-ignore` 反向核对（11-24）
16. **禁止对含解包产物的目录整树 `git add -A`**：本项目的 `临时存档/`、`06_二期自制移植/` 里装着 `.ko/.mbn/.elf/.cpio` 派生二进制，整树 add 一次就误吞 5212 件 89MB 进历史。批量 add 只允许走 `find -size -N M -type f \( 扩展名白名单 \)` 生成清单，然后**必看** `git diff --cached --shortstat` 与扩展名分布（11-24，我犯过两次）
17. `git status` 默认把 CJK 路径输出成八进制转义，脚本若拿它去判断文件存在会**全部落空且静默少加**；必须 `git -c core.quotepath=false`（11-24）
18. **`du` 在本项目报的是表观大小，不是磁盘实占**：空间账只认 `Get-Volume D` 的 `SizeRemaining` 差值，或 `fsutil file queryallocRanges`。本项目曾用 du 得出"回收 133G"的错误结论（实测卷级 0G）
19. **暂存镜像目录多是 `cp -al` 造的硬链接副本**：`临时存档/` ≥20M 的 237 件里 146 件链接数≥2。删单个链接**不还空间**；算回收量必须把整个链接族一起算（本轮预测 3.69G、实测 9.02G，差额就是链接族整族删除）
20. **删除判据三件套（本轮定稿）**：① 只删未进 git 的（与 `git ls-files` 求交必须为 0）；② 只删 sha256 与 `00_救生包/`、`06/解包区/` 权威源**逐字节相同**的；③ **设备回读件（`rb_*`、`*readback*`）一律保留** —— 它的证据力在"从设备读出来的"，不在内容是否等于源

## 11-26 当日新增坑

21. **`adb pull` / `fastboot` 的中文路径会被 Windows 版 adb 打坏**（实测把 `.../DCIM\DJ\` 拼歪）⇒ 设备与 PC 之间的中转一律走纯英文路径（本项目用 `D:/y700_flash_tmp/`、`D:/y700_backup_20261126/`）。
22. **USB + 无线同时在册时 adb 报 `more than one device/emulator`**，且它会**先失败再让你以为命令坏了** ⇒ 脚本里所有 adb 调用一律带 `-s <serial>`，不要图省事。
23. **`adb reboot edl` 后电脑完全看不到设备** ≠ 没进 9008：**线还在底部口**。9008 也只认**侧边中置口**（换口后 COM5 立刻出现）。这条和 fastboot 同因，以前只记了 fastboot。
24. **脚本末行 `[ $DRY -eq 1 ] && say ...` 会把退出码变成 1**，后台任务据此判"刷写失败"——实际刷成功。⇒ 收尾用 `if/fi` + 显式 `exit 0`；**判成败看运行态与日志，不看任务退出码**。
25. **守候/监控脚本两连坑**：① 只过滤 `USB/AndroidUsbDeviceClass` 会漏掉 Ports 类，9008 枚举事件全丢；② `nohup ... &` 随父任务被回收 ⇒ 必须 `setsid nohup`。
26. **`su` 报 `Permission denied` 有两种**：屏幕息屏时 `input tap` 被吞、`uiautomator dump` 出空（先点亮屏幕再看授权页）；ZUI 会拦超级用户后台弹窗，需**用户在屏幕前手动放行一次**。都不是 Magisk 坏了。
27. **写面禁区不能用 `grep -E 'persist|frp|...'` 判**——会命中 xml **文件名**里的同名字导致几乎全表命中；必须按分区标签列判定。另：官方写面**确实含 `logfs` 与 GPT**，与 C17 期"剔除 GPT"的经验相反，别再照搬。

（另：`pm disable-user` 对 PERSISTENT 件无效、Zygisk 注入要看 zygote64 maps 里的 `libzygisk.so` 而不是 grep "magisk"、`magisk --denylist add` 要求包已安装、`find /sdcard` 不加尾斜杠漏符号链接 —— 这四条已入 `android-port-discipline` 技能坑表。）
