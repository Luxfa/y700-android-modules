## B. 构建期最硬的一课：启动链是一个整体，不能只改一半

**v1 失败的唯一致命根因：fstab 声明的文件系统类型与实打出来的镜像不一致。**

- 联想 2.5 的 fstab 把 system/system_ext/product 声明成 `ext4`，而 009b 用 `mkfs.erofs` 重打出的镜像 magic = `e2e1f5e0`（erofs）；my_* 八个分区根本没有挂载行 → `first_stage_mount` 挂载失败 → boot 重试计数耗尽 → `slot-unbootable:a` → 掉回 fastboot。证据：010 规格书 §0、012 审计 A 节 ramdisk 全树 diff（**唯一差异文件就是 fstab.qcom**）、深审计 13 件矩阵（11 erofs + 2 ext4，与手术面完全吻合）。
- 总管自检的路线错误：裁定"最小改动、保联想启动链"，却**保留了联想 vendor_boot 而没同步做 fstab 适配**，偏离图纸 A 系"启动链整套换供体"。

规矩（B 系列）：
1. **B1 改了镜像格式就必须改 fstab**，二者是一个改动包，不许拆成"下一版再说"。
2. **B2 每个逻辑分区落盘后先读 magic 再进 fstab 核对**（`xxd` @0x400 判 ext4/erofs），逐分区列矩阵，不抽样。
3. **B3 换内核/换格式前先验内核是否内置该 fs 驱动**：本次在 2.5 boot.img 内核二进制内实测到 `erofs` 符号才放行 erofs 方案（深审计 §1）。
4. **B4 动了 vendor_boot 必须重算 vbmeta_a 的 HASH 描述符**（salt + image_size + 新摘要），否则 AVB 链断；v1.1 用 make_vbmeta.py 重算并被 parse_vbmeta 独立复核（012 D 节）。
5. **B5 手术面用"全树 diff 只允许命中目标文件"来证明零外溢**——这是本项目目前最强的一道验收（012 A 节）。

## D. 物理连接坑（迷惑性极强，别再试错）

1. **D1 fastboot 只认侧边中置 USB-C**。底部口在 fastboot 下枚举成 MTP 形态（VID_17EF&PID_7FE1）被 Windows 错绑 wpdmtp，表现为"fastboot 完全静默、无提示音"；ADB 两个口都正常。**ADB 通 ≠ fastboot 通。**
2. **D2 驱动**：Google usb_driver r13 手动绑 Android Bootloader Interface，须**取消勾选"显示兼容硬件"**。
3. **D3 进 EDL（唯一实测成功）**：Recovery 选关机 → 静等 10 秒 → **只按音量上** → 插侧边口 → 5 秒松手；全程黑屏即成功。音量上+下同按、或三键强制重启，都会进 Recovery 而不是 EDL；`fastboot oem edl` 在锁定/特定 BL 下被拒。
4. **D4 退 EDL**：三键同按约 10 秒做 PMIC 硬复位；**单独长按电源无效**（PBL 不轮询按键）。
5. **D5 进 Recovery 做 Factory data reset** 是本项目已两次验证的"userdata 被擦/密钥不符（init_user0_failed）"解法；但 A 槽带 `unbootable` 标记时 `fastboot reboot recovery` 会被一起挡掉（05:52 实测）。
6. **D6 Bootloader_SN** 从 `fastboot getvar all` 的 BL_UNLOCK_SN1+SN2 拼接；本机 `ro.boot.bootload_sn` 属性不存在，别在属性里找。

## E. 工具链与配方（照抄即可，别再重新试）

- **E1 super 重组**：`lpmake` 显式写 `_a/_b` 分区名 + `--virtual-ab`（**不用 `-x`**），`--alignment-offset` 省略走默认；2.5 几何（20GiB、LBA 8968–5251847、metadata 64MiB、flags=0x1=VIRTUAL_AB）可直接照抄官方。007 干跑一把成、回读校验值逐字节一致。
- **E2 ext4 重打**：因 `shared_blocks` 不能原地改，走**抽树重打**；erofs 重打需**先内核挂载取 xattr/标签**再 `mkfs.erofs` 回放（009b）。
- **E3 EROFS 多 pcluster**：破解方法已固化在 `erofs_read.py`（marker 链 walk），不要重写解析器。
- **E4 sepolicy 校验降级**：本机 secilc 过旧编不动 A17 CIL（244 处 neverallow），当前用**引用级核查**替代；全量复验属待补项（011d）。
- **E5 防回滚**：C17 基线 vbmeta_system rollback=2026-08，低于 2.5 的 2026-09——跨版本混件前必查 rollback 索引（005c）。
- **E6 供体身份**：一加 OPD2513 包内 `my_manifest` 实为 OPD2515/OP6548L1（Pad mini）型录，别拿 model 名当结论（006 意外项）。

## H. 未收口（本台账不假装已解决的事）
