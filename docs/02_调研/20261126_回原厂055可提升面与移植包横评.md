## 一、版本构成勘误（先纠正两条我们自己的说法）

**原结论**：昨天§一百零七写"055 是 Android 17 世代，包内指纹 `Lenovo/TB323FU_PRC/TB323FU:17/CQ2A.260712.001/ZUXOS_2.5.10.055_261102_PRC`"。
**实际证据**：那个串来自**设备侧**快照 `04_日志与分析/参照快照_C17可开机_20261123_2022/getprop_full.txt:1135` 的 `ro.odm.fingerprint.update`，**不是包内文件**；我当时没打开包核对就写成了"包内指纹"，缺的那一步是抽 `build.prop`。
**更正后的事实【实测，本人复核】**：

| 分区 | 关键字段 | 判定 |
|---|---|---|
| system（super_4） | `ro.build.display.id=TB323FU_CN_OPEN_USER_Q00037.0_A17_ZUXOS_2.5.10.055_ST_261102`、`release=17`、`sdk=37` | 系统层确实是安卓 17 |
| vendor（super_7） | `ro.vendor.build.version.release=16`、`sdk=36`、`ro.vendor.build.id=BQ2A.260402.002-BP2A.250705.008`、构建时间 `Mon Nov 2 2026` | **HAL 层还是安卓 16** |

⇒ 所谓"安卓 17 的原厂包"是**17 的系统层 + 16 的 vendor 层**混搭，与我们手上 C17（`ro.build.id=CP2A.260605.016` vs `ro.vendor.build.id=BQ2A.250831.001-BP2A.250605.031.A3`）是**同一种混搭形态**。这条对"回不回原厂"很关键：回原厂并不等于"整套换新"。

⇒ **UI 这一面，原厂比移植包强在"东西本来就齐"**（电脑模式、一视界、分屏参数、PC 版 WPS 全在预装里），而 dock 缩水这类是**联想自己写死**的，换系统/降级都躲不开，除非整包换 Launcher。

> **【11-26 17:4x 更正本节结论——原结论过宽】**
> - **原结论**：dock 6 槽"写死、改不动"（§三 全节 + 本文 §八 排序都据此把 UI 面判成"基本没戏"）。
> - **实际证据**：静态资源层确实写死（`resources.arsc` 的 `numHotseatIcons`、hotseat 布局只到 `hotseat_icon_6`、`is_layout_locked=true`、92 个 RRO 无一针对 Launcher，这些都复核有效）；**但运行时 hook 层是活的**——社区项目 ZTool 直接 hook `com.zui.launcher` 做出"解锁 Dock 固定应用数上限""允许关闭 Dock""自定义桌面网格""图标大小突破系统 0.6~1.3 倍率""无字模式""大文件夹对齐""批量卸载"〔一手 README〕。
> - **缺的那一步**：只查了"能不能用 RRO/apk 资源覆盖"，**没有把"运行时 hook"当成一条独立路径评估**，于是把"静态层改不动"错误外推成"整个 UI 面改不动"。
> - **修正后的口径**：UI 面 = 静态层写死（成立）+ hook 层可改（代价是先上 Xposed 载体，且 A17 上载体本身有"管理器在但不注入"的坑）。详见 `20261126_社区模块与插件横评.md` §九。

## 六、游戏"不开挂"提升（只做系统/硬件层，不碰游戏进程）

1. **关杜比/空间音效**＝听声辨位第一性价比项。老话"Y700 吃鸡必关杜比全景声"多年流传 + NGA 实测"虚拟环绕清晰但分不清方向" + **我们本机 11-26 已实锤**：QTI quasar 空间音效导致蓝牙电流声，关掉即愈。【多人实测 + 本机实测】
2. **耳机走另一个 C 口**：有线 5～30ms；蓝牙 SBC/AAC 150～250ms、aptX Adaptive/LC3 30～80ms。双 C 设计的正确用法就是一个口充电、一个口挂耳机。"红魔 8ms""LDAC 打游戏够用"属内容农场口径，已剔除。【规格 + 多实测】
3. **AI 像素/触控超分类开关**（游戏助手内）：B站复测建议打开，开镜更平滑。【单人实测（较可信 UP）】
4. **触控采样率别折腾**：240→480Hz 理论差 2ms，低于感知阈；真正变量在触控 IC 固件，root 层无改法，"强开 480Hz 模块"属玄学。贴膜厚度与手汗比任何模块有效。【官方 + 科普共识】
5. **VSYNC 相位偏移 / `debug.sf.*`**：AOSP 文档确认存在、1～2ms 可感知，但它是编译进 BoardConfig/设备 xml 的，**没有五代运行时覆盖成功的社区实证**，SELinux + 只读分区会挡。【官方文档有 / 社区实证无 → 别当作业抄】
6. `aaudio.mmap_policy=2/3`（EXCLUSIVE）是官方低延迟开关，但无调优设备强开会爆音——先实测本机往返延迟再决定。【开发者文档】
7. **网络**：C 口接以太网适配器（帧稳定性收益最大）；关"WLAN 始终扫描/智能切换"。头条系"关省电 76ms→21ms"是 AI 稿，方向可参考、数字不可信。【通用经验 / AI稿已剔除】
8. 双 X 轴马达的社区可调参数**零实证**。【无实证】

| mainline Linux 双系统（`joonhoekim/tb323fu-linux`） | 能玩/部分日用 | 真 PC 环境、freedreno Vulkan1.4、165Hz、硬解 4K、双摄、笔、双马达 | 8K HEVC10bit 解不了、簇 idle 重启、旁路充电仍报 Charging、GNSS 无天线 | 强（一手仓库 hardware-status） |
| 澎湃OS3/4、OriginOS、MagicOS、鸿蒙 | **五代不可用** | — | 五代无公开包（需 SM8850 对应厂底包）；鸿蒙 NEXT 已去 AOSP 兼容层 | 强 / 中 |

**"机型身份 vs 服务端白名单"这条已被证实**（也解释了我们 11-24 伪装调研的疑问）：B站有人给五代刷"改机型模块"伪装红魔 Pad3Pro，和平精英**当场多出 165 帧档**，代价是游戏助手变默认、需再补专用模块；另一帖说明用模块而不用 LSPosed 的原因是"三角洲会检测密钥"。DRM 侧：四代 A15 只有 L3、升 A16 拿到 L1 但 Netflix 仍降 L3；二代锁 BL + ROW 固件才稳 L1；关键是**联想 bootloader 用 AOSP 测试公钥**，所以"带锁刷签名固件"能保 TEE/L1。

⇒ 移植包**永远追不平**原厂的六类东西：服务端名单类（机型帧率档、超分插帧、触控超分）、温控与调度对本板的标定、充电协议与 ICharger 一族原生服务、相机原厂算法、TEE/Widevine L1 与银行支付、OTA 与防回滚账本（外加保修残值与手写笔/灯环/抬起亮屏）。**这不是"包不够好"，是身份换了后端就不认**。

## 八、性价比排序（若决定回原厂）

1. 禁 OTA + 装 root 隐藏环境（保命项，不做这条后面全白做）
2. 温控/帧率阶梯模块：覆盖 `thermal-engine_{cpu,gpu}_0.conf` + `thermal_user_case.conf` + `thermallevel_to_fps.xml` + `qapegameconfig.txt`，工艺沿用现有那套（`post-fs-data.sh` bind mount、`chcon u:object_r:vendor_configs_file:s0`、纯 ASCII 不加注释、整机重启生效）
3. resetprop `ro.surface_flinger.game_default_frame_rate_override` 与 `ro.media.recorder-max-base-layer-fps`
4. 165Hz 三连开 + 游戏助手"极致" + 关杜比/空间音效 + 有线耳机挂另一个 C 口
5. 最后才是 Launcher/桌面类整包替换（收益主观、代价最大）

## 九、缺口（下次要补的取证）

1. odm / vendor_dlkm / system_dlkm / modem 四个镜像**没解**：`power_profile.xml`、蓝牙固件 `.btfw/btnx`、音频 `.ko`、`thermal_info_config.json` 的判定都卡在这里——**不能据此说原厂没有**。
2. dock 能否用自建 RRO 覆盖：需要查 `ZuiLauncher.apk` 的 `overlayable.xml`（未做）。
3. 耳机识别与录屏掉帧：必须真机 `getevent` / 录屏 trace，包内到顶了。
4. 降级 026 是否真比 055 强：**社区没有独立 A/B 数据**，我们有 9008 和备份，理论上可以自己测——但那是"值不值得"的问题，不是取证能力问题。

## 补记（11-26 11:2x）：ROW 国际版原件核对 + 三套底层世代对照

**为什么补**：第七节把 ROW 列为"值得试的第二个包"，依据来自派单会话转述。我本人去镜像站把原文件名拉下来核对后，**结论要改口径**——ROW 不是"更新的系统"。

**镜像站原件【实测，本人直取目录页】**（`mirrors.lolinet.com/firmware/lenowow/2026/Legion_Y700_Gen5_2026/`，两目录均 2026-08-27 上架）：

| 文件 | 平台 | 构建日期 | 大小 |
|---|---|---|---|
| `TB323FU_ROW_OPEN_USER_Q00020.0_A16_ZUI_18.0.10.084_ST_260421.7z` | **A16** | 2026-04-21 | 5.19 GB |
| `TB323FU_ROW_OPEN_USER_Q00020.0_A16_ZUI_18.0.12.104_ST_260711.zip` | **A16** | 2026-07-11 | 6.41 GB |
| `TB323FU_CN_OPEN_USER_Q00020.0_A16_ZUXOS_2.0.12.088_ST_260610.7z` | **A16** | 2026-06-10 | 10.17 GB |

⇒ 镜像站上**没有** 055，也**没有**任何 A17 件；CN 目录只有安卓 16 的 `2.0.12.088`。刷 ROW 拿到的是 **ZUI 18 命名下的安卓 16、7 月构建**，比救生包里那份 055（11 月构建、system 侧安卓 17）**旧约四个月**，且国行的天禧 AI、部分游戏助手权益、安全补丁一并失去。

**三套底层世代对照【实测，包内/快照 build.prop 直读】**：

| 组件 | C17（我们现在跑的） | 原厂 055 | 原厂 ROW 18.0.12.104 |
|---|---|---|---|
| system | 安卓 17（`CP2A.260605.016`，OPPO 件） | 安卓 17（`CQ2A.260712.001`/A17 串，联想件） | 安卓 **16** |
| vendor/odm | 安卓 **16**（`BQ2A.250831.001-BP2A.250605.031.A3`，构建 2026-10-06） | 安卓 **16**（`BQ2A.260402.002-BP2A.250705.008`，构建 2026-11-02） | 安卓 16 |
| 结论 | **底层与 055 同属安卓 16 世代**，只差约一个月构建 | HAL 换代风险面小 | 整体退一代 HAL |

⇒ 由此修正第七节推荐顺位：**ROW 只在"确实需要 GMS/Play"时才值得**，它不构成"比原厂更好"的选项；对日用 + 游戏这两条主用途，排序仍是 **留在 C17（自维护）或回原厂 055 + 本清单模块 > 降级 026 > ROW**。
