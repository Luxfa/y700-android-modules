## 问题二：SM8850（骁龙8 Elite Gen5）同平台移植的外部佐证

### 结论速览

1. **有人成功过**：ColorOS 17 已被移植到非欧加机型且以 **一加15（PLK110，SM8850）官方包为供体**——小米13（fuxi）移植版基于 PLK110_17.0.0.100（fiime 收录，2026-09-28）；小米6 刷入 ColorOS 17.0 的包也被指"是一加15的包"（smzdm，2026-09-19~20）。即 SM8850 供体包外溢移植已成社区惯例。
2. **踩坑清单有实据**：指纹（锁屏指纹解锁失效/指纹 HAL 与系统应用不兼容致闪退）、相机（移植版首版无可用相机 App）、persist 分区丢失致指纹无法录入、vendor 被覆盖致 WiFi 打不开、vbmeta 未禁 AVB 致反复进 recovery、快充协议未适配 vendor 致慢充、官方 OTA 必然断档。
3. **跨版本混刷的 Bootloader 侧坑**：一加13 升 C17 后 abl 不匹配导致无法进 Bootloader，修复=刷回旧版本 ROM 包里的 abl.img——与我们"2.5 底 + C17 供体"的混拼结构直接相关（底层件保旧是社区共识做法）。
4. **dtbo 适配是真实工序**：大侠阿木的一加12 PPS 充电模块会自动 patch dtbo 分区（且升级/平刷后 dtbo 被覆盖需重打），佐证 dtbo 在欧加系适配中承担充电策略等硬件使能。
5. **Y700 五代自身的前科**：五代 C16 移植包（GUF26）已知问题=TEE/支付/DRM 存疑、32位应用不支持、查找定位失效、游戏助手可能失效、震动阉割、无官方 OTA；四代"免解锁直刷"路径五代不可复制（五代 9008 需授权、AVB 强化）。

### 对"2.5 底 + 105 供体"组合的映射（仅证据陈列，不做裁定）

- 105 供体与 2.5 内核同基线（006 已验），而外部案例显示**跨代移植（865→C17 供体）都能开机进系统**，同平台同基线的难度预期更低——但外部案例中指纹/相机仍是最常见的两个翻车点，与本项目风险清单一致。
- "底层件保旧"（abl/vbmeta/boot/dtbo 用 2.5 的）在社区案例中反复出现（一加13 abl 案例、dtbo patch 案例），与 005c 拆解结论（vbmeta 重生成、内核换 OPlus 系）方向一致。
- 指纹：Y700 五代 C16 已有 TEE/支付存疑前科；小米13 C17 移植首版锁屏指纹失效——C17 移植后指纹/支付应列入首批实测项。

## 未证实/存疑项（缺口）

1. **精确版本 17.0.0.105 未在公开渠道命中**：大侠阿木在架 103/104/201，紫罗兰通道的 105 未找到第二个来源；若只需同机型 C17 供体，104/201 可替代，若必须精确 105 则需紫罗兰通道续传或找群友分流。
2. **官方直链裸下可行性未实测**：component-ota-cn.allawntech.com 直链存在，但站点明示"仅供一键ROOT工具"，直接下载可能被拒（未实测，标注未证实）；如需验证建议浏览器/IDM 手工试，本线未执行下载动作。
3. **SM8850 平板→平板的直接互刷案例未命中**：找到的成功案例均为手机移植（小米13/小米6/一加8T）与 Y700 五代 C16 案例；Pad mini→Y700 五代这类同平台平板组合除本项目紫罗兰供体外未见第三方实操帖。
4. **C17 移植后指纹/支付在五代上的实测反馈未命中**：五代 C17（紫罗兰包）尚在下载阶段，社区未见刷后报告；五代 C16 的 TEE 存疑是最接近的参照。
