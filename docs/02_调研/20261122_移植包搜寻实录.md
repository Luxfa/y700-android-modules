## 对项目的直接可用情报（非包类）

- **解锁命令序列（社区实证）**：`fastboot flash unlock sn.img` → `fastboot oem unlock-go` → 平板出现 UNLOCK 提示时**长按开机键确认** → 完成后 `fastboot devices` 显示 device unlocked。已写入作业指导书。
- **防回滚红线（官方熔断机制）**：不解锁 BL 直接刷**旧版** ZUI 线刷包 = 变砖卡红字。含义：①版本对齐（043→088）走**官方OTA**（升不降级，安全）；②任何降级必须先解锁。
  > **2026-11-25 勘误**：此处"熔断"应读作 **AVB rollback index**（判据只看 `boot` + `vbmeta_system` 两个镜像的回滚值），**不是** eFuse 硬件熔断；欧加 ColorOS 16.0.3.501+ 那套 `xbl_config` 熔断**不可外推到 Y700 五代**。另：本行的"043→088"属 `ZUXOS_2.0.1x` 编号，与我方在跑的 `ZUXOS_2.5.10.055` **不是同一套记法，不要混用**。详见 `02_调研/20261125_论坛挖宝结论表.md` 6.1/6.2。
- **五代 ColorOS 已知问题清单（GUF26 包，四代实测+五代用户反馈）**：查找定位不可用；热点 5G 频段需与 ColorOS 手机互联一次才出现（无则 2.4G）；旁路供电可用但退出游戏要切回否则充不进电；改机型后游戏助手失效（需恢复模块）；个别报告蓝牙耳机音量异常、充电发热。
- **root 方案风向**：五代社区主流已转 KSU/SukiSU 内核 root（隐藏环境优于 Magisk，游戏标记问题更少）；KowSU 管理器、欧加真 SukiSU_GKI 内核 AK3 见 bszip.me/jc。
